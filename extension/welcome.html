Set up the voice engine

Reading happens on your own computer. This extension talks to a small, free voice engine you run locally; nothing you read is sent anywhere.

Checking for the engine…

  1. Install uv

    The Python installer the engine uses. Skip this if uv --version already works.

    curl -LsSf https://astral.sh/uv/install.sh | sh
    powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

  2. Install the engine

  3. Start it

    sawt serve

    The first start downloads the voice model once (about 350MB). Leave the window open while you listen. On macOS, sawt agent install starts it at login instead, so you never think about it again.

You're set

Open any article and press Alt+R, or click the toolbar icon. Right-click selected text to hear just that.
