# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, and keep criticism about the code, not the person.
Harassment, personal attacks and discriminatory language are not tolerated in issues, pull
requests, discussions or anywhere else the project lives.

Report unacceptable behaviour privately to the maintainer through a
[GitHub security advisory](https://github.com/muneebsajjad/sawt/security/advisories/new)
(it is the one private channel the repository has). Reports are read in confidence, and the
maintainer may remove content or ban participants who break these rules.
